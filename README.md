AI Enemy GYM - Assignment 2 Tyler Stow

Project Description: This project was created using Unreal Engine 5 and it contains an enemy AI which patrols a small map.
The Enemy AI is able to see the and chase the player and is able to react and investigate sounds.
The player is able to run from the Enemy AI and make the AI lose track if you stay out of its visible range for 5 seconds.
The player is also able to throw a simple ball object to make the enemy go and investigate where the ball landed as long as the ball lands within the hearing range of the AI.

Controls: W - Forward, A - Left, S - Backward, D - Right, Mouse - Look Around, Q - Throw Ball
